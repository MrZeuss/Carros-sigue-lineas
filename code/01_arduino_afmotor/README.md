# Arduino + AFMotor

Plataforma basada en Arduino Uno/Nano con Motor Shield compatible con la librería `AFMotor`.

## Contenido inicial
- `01_prueba_motores/01_prueba_motores.ino`: prueba básica de dos motores.
- Próximamente: lectura de sensores, control proporcional y PID.

## Configuración usada
- Motor izquierdo: canal M1.
- Motor derecho: canal M2.
- Velocidad PWM: 0 a 255.

Esta plataforma sirve como versión inicial para validar mecánica, sentido de giro y alimentación antes de integrar los sensores de línea.
