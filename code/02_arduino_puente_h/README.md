# Arduino + puente H

Plataforma basada en Arduino Uno/Nano y puente H externo para dos motores DC.

## Asignación de pines usada

| Función | Pin Arduino |
|---|---:|
| ENA motor izquierdo | D3 (PWM) |
| IN1 | D6 |
| IN2 | D7 |
| IN3 | D8 |
| IN4 | D9 |
| ENB motor derecho | D5 (PWM) |

Esta asignación corresponde a una de las configuraciones que hemos utilizado en los carros con dos motores amarillos y puente H.
