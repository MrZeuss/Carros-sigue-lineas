# Sensores

Documentación de las distintas tecnologías utilizadas en los carros sigue líneas.

- Sensores digitales de línea.
- Sensores analógicos de reflectancia.
- Barras de 5 sensores TCRT5000.
- Barra analógica de 8 canales mediante ADS1015/I2C.
- Sensores ToF VL53L0X para paredes y obstáculos.

La barra I2C de ocho canales se mantiene como proyecto independiente en `MrZeuss/barra-linea-i2c` y se enlazará desde aquí.
