# Hardware

Subcarpetas destinadas a documentar cada generación del robot:

- `arduino_afmotor/`
- `arduino_puente_h/`
- `esp32_puente_h/`
- `esp32_do/`
- `sensores/`
- `alimentacion/`

Cada plataforma tendrá tabla de pines, esquema de conexiones, alimentación, driver de motores y sensores compatibles.
