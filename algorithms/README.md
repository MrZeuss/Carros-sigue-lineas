# Algoritmos de control

Esta carpeta documentará algoritmos independientes del hardware:

- Control binario.
- Normalización de sensores.
- Posición ponderada de la línea.
- Error respecto del centro.
- Control proporcional (P).
- Control PID.
- Recuperación de línea perdida.
- Detección de intersecciones.
- Estrategias de navegación en laberintos.
